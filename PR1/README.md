# Energy Consumption Tracking – система учёта энергопотребления

## Назначение

Консольное приложение для учёта энергопотребления объектов управляющей компании.

Приложение позволяет фиксировать показание счётчика на объекте и рассчитывать расход.

## Целевая аудитория

Сотрудники управляющей компании.

## Предметная область

Учёт потребления ресурсов по объектам недвижимости.

## Основные сущности

- объект
- счётчик
- показание
- период

## Основные функции

- проверка корректности показания
- расчёт расхода
- вывод статуса учёта

## План развития

На следующих этапах планируется:

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
