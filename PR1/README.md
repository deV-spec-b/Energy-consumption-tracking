# Energy Consumption Tracking – система учёта энергопотребления

## Назначение

Консольное приложение для учёта энергопотребления объектов управляющей компании.

Приложение позволяет:

- просматривать и добавлять объекты;
- находить объекты по адресу;
- добавлять счётчики к объектам;
- вносить показания;
- рассчитывать расход;
- работать с периодами учёта;
- хранить данные в JSON-файлах.

## Целевая аудитория

Сотрудники управляющей компании.

## Предметная область

Основные сущности: объект, счётчик, показание, период.

## Основные функции

- добавление и поиск объекта;
- добавление счётчика;
- внесение показания;
- расчёт расхода по счётчику;
- расчёт расхода за период.

## Хранение данных

- data/objects.json
- data/meters.json
- data/readings.json
- data/periods.json
