# Energy Consumption Tracking – система учёта энергопотребления

## Назначение

Energy Consumption Tracking – консольное приложение для учёта энергопотребления объектов управляющей компании.

Приложение позволяет:

- просматривать объекты учёта;
- добавлять объекты учёта;
- находить объекты по адресу;
- сортировать объекты по площади;
- просматривать счётчики;
- добавлять счётчики и привязывать их к объектам;
- находить счётчики по номеру;
- просматривать показания;
- вносить показания по счётчику;
- рассчитывать расход по счётчику;
- просматривать периоды учёта;
- добавлять периоды;
- рассчитывать расход за выбранный период;
- хранить данные между запусками приложения.

## Целевая аудитория

Сотрудники управляющей компании, которым необходимо вести учёт объектов, счётчиков и показаний и рассчитывать потребление за период.

## Предметная область

Основными объектами предметной области являются:

- объект;
- счётчик;
- показание;
- период.

Объект представляет квартиру, помещение или здание, по которому ведётся учёт.

На объекте устанавливаются счётчики разных типов (электроэнергия, вода, газ).

По счётчику фиксируются показания на конкретную дату.

Период задаёт интервал дат, за который рассчитывается потребление.

Расход считается как разница между крайними показаниями счётчика внутри выбранного периода.

## Основные сущности

### Объект – AccountingObject

Объект `AccountingObject` представляет объект учёта.

Основные атрибуты:

- `id` – уникальный идентификатор объекта;
- `address` – адрес объекта;
- `object_type` – тип объекта;
- `area` – площадь объекта.

Основные методы:

- `__str__()` – строковое представление объекта.

Имя класса в коде – `AccountingObject`, а не `Object`, потому что `object` в Python является встроенным типом. Предметная сущность при этом остаётся той же: «Объект».

### Счётчик – Meter

Объект `Meter` представляет прибор учёта.

Основные атрибуты:

- `id` – уникальный идентификатор счётчика;
- `number` – заводской или учётный номер;
- `meter_type` – тип счётчика;
- `accounting_object` – объект `AccountingObject`, на котором установлен счётчик;
- `status` – статус счётчика.

Основные методы:

- `deactivate()` – вывод счётчика из эксплуатации;
- `belongs_to()` – проверка принадлежности счётчика объекту;
- `__str__()` – строковое представление счётчика.

### Показание – Reading

Объект `Reading` представляет показание счётчика.

Основные атрибуты:

- `id` – уникальный идентификатор показания;
- `meter` – объект `Meter`;
- `value` – значение показания;
- `reading_date` – дата снятия показания.

Основные методы:

- `is_later_than()` – сравнение дат двух показаний;
- `__str__()` – строковое представление показания.

### Период – Period

Объект `Period` представляет период учёта.

Основные атрибуты:

- `id` – уникальный идентификатор периода;
- `name` – название периода;
- `start_date` – дата начала;
- `end_date` – дата окончания.

Основные методы:

- `contains()` – проверка, входит ли дата в период;
- `__str__()` – строковое представление периода.

## Основные функции

- добавление объекта;
- поиск объекта по идентификатору и адресу;
- добавление счётчика;
- поиск счётчика и отбор счётчиков объекта;
- внесение показания;
- расчёт расхода по счётчику;
- добавление периода;
- расчёт расхода за период.

## Хранение данных

Данные приложения хранятся в JSON-файлах:

- `data/objects.json`;
- `data/meters.json`;
- `data/readings.json`;
- `data/periods.json`.

При загрузке данные из JSON преобразуются в объекты `AccountingObject`, `Meter`, `Reading` и `Period`.

При сохранении объекты преобразуются в данные JSON.

Для связи счётчика с объектом в `meters.json` используется идентификатор `object_id`.

Для связи показания со счётчиком в `readings.json` используется идентификатор `meter_id`.

## Назначение модулей

### `main.py`

Точка входа в приложение.

Отвечает за:

- запуск приложения;
- отображение меню;
- получение данных от пользователя;
- организацию пользовательских сценариев.

### `models/objects.py`

Содержит класс `AccountingObject` и функции работы с объектами.

### `models/meters.py`

Содержит класс `Meter` и функции работы со счётчиками.

### `models/readings.py`

Содержит класс `Reading` и функции работы с показаниями.

### `models/periods.py`

Содержит класс `Period` и функции работы с периодами.

### `storage.py`

Отвечает за загрузку и сохранение данных.

Выполняет преобразования:

- JSON → объекты Python;
- объекты Python → JSON.

### `utils.py`

Содержит вспомогательные функции:

- `input_int()` – безопасный ввод целого числа;
- `input_float()` – безопасный ввод вещественного числа.

### `tests/`

Содержит автоматизированные тесты проекта.

## Текущий этап разработки

На ПР7 данные системы учёта энергопотребления перенесены из JSON в базу данных SQLite:

- создана база данных `data/energy.sqlite`;
- таблицы созданы с помощью `sql/schema.sql`;
- данные перенесены из JSON скриптом `db/import_json.py`;
- SQL-запросы сохранены в `sql/queries.sql`;
- Django-представления получают данные из SQLite;
- страницы списка объектов, счётчиков и показаний работают с базой данных.

На следующих практических работах база данных будет подключена к Django с использованием Django ORM.
